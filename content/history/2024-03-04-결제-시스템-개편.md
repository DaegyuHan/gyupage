# 결제 시스템 개편 프로젝트

> 예시 문서예요. 이 파일을 지우고 내 문서를 넣으면 돼요.

## 배경
- 레거시 결제 모듈이 PG사 3곳에 각각 하드코딩되어 있었음
- 신규 PG 추가 시 2주 이상 소요

## 내가 한 일
1. PG 연동부를 어댑터 패턴으로 분리
2. 결제 상태 머신 도입
3. 정산 배치 재작성

### 기술 스택
| 영역 | 사용 기술 |
| --- | --- |
| API | Spring Boot |
| 배치 | Spring Batch |
| DB | MySQL |

## 결과
- 신규 PG 연동 기간 **2주 → 3일**
- 결제 실패율 1.2% → 0.4%

## 회고
```text
상태 머신을 처음부터 도입했으면 더 좋았을 것
```
